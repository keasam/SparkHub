# SparkHub — Idea to IPO

Mobile-first idea evaluation platform.

Core flow:
- Submit an idea and supporting documents
- Generate 9 personalized AI challenge questions
- Answer each in 60 seconds
- Evaluate answers, idea data, and market evidence
- Show a compelling teaser
- Unlock the full evaluation for ₹199

## Development

The initial app is being bootstrapped as an Expo / React Native project. AI, document processing, market research, authentication, and payments are structured as integration points so the product can evolve without rewriting the core experience.
